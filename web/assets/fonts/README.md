# Interface fonts

Noto Sans SC and Noto Serif SC, downloaded as text subsets from Google Fonts for this demo. Fonts are served locally. Characters outside the subsets use the CSS system fallback.

Both font families are licensed under the SIL Open Font License 1.1.
